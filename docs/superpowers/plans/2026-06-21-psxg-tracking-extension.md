## Conventions (apply to every task)

- **Test-first.** Each task lists its failing test FIRST; write it, watch it fail, implement, watch it pass. No implementation lands without its test.
- **Local gate before "done":** `uv run ruff check`, `uv run ruff format --check`, `uv run pyright src`, the task's `pytest`. dbt models: `dbt build --select <model>` + contract test.
- **Commit boundaries:** one logical task per commit; **no commits/PRs without explicit user approval** (CLAUDE.md). Bronze migrations applied with the merge via `_runner.py`.
- **Done-when** per task = test green + local gate clean + acceptance bullet satisfied.

- A richer (>2 feature) PSxG model + per-provider calibration covariate — **explicitly deferred (user 2026-06-21)**; `shot_speed`/GK-position/pressure stay reserved, single pooled Platt (spec §8/E).
- The exact pooled-layer floor *values* + band render specifics — a UX requirement the GK-page session confirms. The *structure* is pinned in spec §10: percentile **deferred** (`ranking_enabled` gate, default 20 GKs × 20 shots), raw `goals_prevented` + **Poisson-binomial** band (A1), show-value floor 5, `low_sample` the norm (C2). (Supersedes the earlier "default 30 / bootstrap" — both retired by the volume finding + A1.)
