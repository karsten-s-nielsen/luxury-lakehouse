# CRITICAL: Tensor Shape Rules

ALL tensors inside custom_embed are 3D: (batch, seq_len, hidden_dim).

## Input shapes
- action_ids, start_x, start_y, end_x, end_y, result, time_delta, player_ids:
  ALL are (batch, seq_len) — one scalar per token.

## Embedding/MLP output shapes
- self.player_embedding(player_ids) -> (batch, seq_len, hidden_dim)
- self.token_embedding(action_ids) -> (batch, seq_len, hidden_dim)
- self.start_x_mlp(start_x) -> (batch, seq_len, hidden_dim)
- self.result_embedding(result) -> (batch, seq_len, hidden_dim)
- Every self.*_embedding() and self.*_mlp() returns (batch, seq_len, hidden_dim).

## Common shape errors that score 0
- NEVER use .unsqueeze(1) on player_emb or action_emb — they are ALREADY 3D.
  player_emb.unsqueeze(1) creates (batch, 1, seq_len, hd) which is 4D and
  will crash with "4-D query tensor" or shape mismatch errors.
- NEVER use .expand() to broadcast embeddings — shapes already match.
- Keep all intermediate tensors exactly (batch, seq_len, hidden_dim).
- Element-wise operations (+, *, torch.sigmoid) preserve shape — prefer these.
- self.player_cross_attn(query, key, value) expects 3D inputs:
  query/key/value must each be (batch, seq_len, hidden_dim).
- torch.cat on dim=-1 doubles hidden_dim — make sure downstream layers
  accept the wider dimension (e.g., Linear(hidden_dim * 2, hidden_dim)).

# Performance Reference

The cross_attention seed achieves rho ~0.56 by registering its own attention
layers via custom_layers and using them in custom_embed:
```python
def custom_layers(hidden_dim):
    num_heads = config["num_heads"]
    dropout = config["dropout"]
    return {
        "player_cross_attn": torch.nn.MultiheadAttention(
            hidden_dim, num_heads, dropout=dropout, batch_first=True,
        ),
        "player_cross_norm": torch.nn.LayerNorm(hidden_dim),
    }

def custom_embed(self, action_ids, start_x, start_y, end_x, end_y,
                 result, time_delta, player_ids):
    player_emb = self.player_embedding(player_ids)
    action_emb = (self.token_embedding(action_ids) + self.start_x_mlp(start_x)
                  + self.start_y_mlp(start_y) + self.end_x_mlp(end_x)
                  + self.end_y_mlp(end_y) + self.result_embedding(result)
                  + self.time_delta_mlp(time_delta))
    attn_out, _ = self.player_cross_attn(query=action_emb, key=player_emb, value=player_emb)
    emb = self.player_cross_norm(action_emb + attn_out)
    return self.embedding_dropout(emb)
```
Note: self.player_cross_attn works ONLY because custom_layers registers it.
Without the custom_layers declaration, this code would crash with AttributeError.

Simple gating patterns (gate * action + (1 - gate) * player) consistently score
rho < 0.05 — they destroy the ranking signal. The attention mechanism is what
drives rho because it allows each action token to selectively attend to the
player context.

To beat the seed, consider:
- Hybrid approaches: attention + gating, multi-head variants, learned residual weights
- Richer player-action interaction: bilinear pooling, FiLM on attention output
- Multi-scale conditioning: different mechanisms for spatial vs temporal features
- SwiGLU fusion: concat(action, player) -> split -> Swish-gated Hadamard product
- Orthogonal attention: project attn output onto complement of action space
- Fourier spatial features: sin/cos projection of (x,y) coordinates before fusion
- Dynamic routing: MoERouter to dispatch different experts by player/spatial context
- Hypernetworks: HyperLinear to generate player-specific transformations
- Do NOT replace attention with simple gating — that is a known regression.
- ALWAYS register any layer you reference in custom_embed via custom_layers.

# Building Blocks

Pre-validated modules available in custom_layers() — no import needed. These
encapsulate complex patterns that are hard to implement correctly from scratch.

## MoERouter(hidden_dim, n_experts=4, top_k=2, temperature=1.0)

Mixture-of-Experts with sparse top-k routing. A small router network selects
which experts process each token based on a conditioning signal.

```python
def custom_layers(hidden_dim):
    return {"moe": MoERouter(hidden_dim, n_experts=4, top_k=2)}

def custom_embed(self, ...):
    # player_emb drives routing, action_emb is processed by selected experts
    routed = self.moe(action_emb, player_emb)  # (B, S, hd)
```

## HyperLinear(hidden_dim, rank=16)

Hypernetwork that generates a low-rank linear transformation conditioned on
input. The conditioning signal (e.g., player embedding) dynamically generates
the weight matrix applied to the input — every player gets a unique transform.

```python
def custom_layers(hidden_dim):
    return {"hyper": HyperLinear(hidden_dim, rank=16)}

def custom_embed(self, ...):
    # player_emb generates weights, action_emb is transformed
    out = self.hyper(action_emb, player_emb)  # (B, S, hd)
```

## KANLayer(in_dim, out_dim, n_basis=8)

Kolmogorov-Arnold Network layer with learnable Gaussian RBF activations on
edges. More expressive than standard Linear+ReLU for continuous inputs like
spatial coordinates, with fewer parameters.

```python
def custom_layers(hidden_dim):
    return {"kan_spatial": KANLayer(4, hidden_dim, n_basis=8)}

def custom_embed(self, ...):
    spatial = torch.stack([start_x, start_y, end_x, end_y], dim=-1)  # (B, S, 4)
    spatial_emb = self.kan_spatial(spatial)  # (B, S, hd)
```

## AdaLNZero(hidden_dim, conditioning_dim=None)

Adaptive Layer Normalization with zero-initialized residual gates (DiT).
The conditioning signal generates scale, shift, AND residual gate for a
LayerNorm + residual connection. Superset of FiLM. Zero-init means the
block starts as pure residual and conditioning is learned incrementally.

```python
def custom_layers(hidden_dim):
    return {"adaln": AdaLNZero(hidden_dim)}

def custom_embed(self, ...):
    normed, gate = self.adaln(action_emb, player_emb)
    # gate controls how much the sublayer contributes:
    emb = action_emb + gate * some_transform(normed)  # (B, S, hd)
```

## CrossLayer(hidden_dim)

DCN-V2 cross layer for explicit polynomial feature interactions.
x_{l+1} = x_base ⊙ (W·x + b) + x. Stacking N layers produces N-th
order interactions. Strictly more expressive than FiLM (first-order only).

```python
def custom_layers(hidden_dim):
    return {
        "cross1": CrossLayer(hidden_dim),
        "cross2": CrossLayer(hidden_dim),  # stack for higher-order
    }

def custom_embed(self, ...):
    x = self.cross1(action_emb, player_emb)  # 2nd-order crossing
    x = self.cross2(x, player_emb)            # 3rd-order crossing
```

## CompetitiveGate(hidden_dim)

Competitive advantage gate from pitch control physics. Gates by the
*relative advantage* between two competing signals — sigmoid(k * (primary - competitor)).
Domain-validated for modeling spatial competition in football.

```python
def custom_layers(hidden_dim):
    return {"comp": CompetitiveGate(hidden_dim)}

def custom_embed(self, ...):
    # player_emb vs action_emb: how much does player context dominate?
    gated = self.comp(action_emb, player_emb, action_emb)  # (B, S, hd)
```

## GradientReversal(lambda_=1.0)

Adversarial debiasing — identity forward, negated gradient backward.
Suppresses a conditioning variable from the representation. Use with
a classification head to push embeddings AWAY from encoding a variable.

```python
def custom_layers(hidden_dim):
    return {
        "grl": GradientReversal(lambda_=0.1),
        "debias_head": torch.nn.Linear(hidden_dim, 8),  # e.g., 8 position types
    }

def custom_embed(self, ...):
    # Main embedding computation...
    emb = ...
    # Adversarial branch (gradient pushes emb away from encoding position type):
    reversed_emb = self.grl(emb)
    _ = self.debias_head(reversed_emb)  # loss computed externally
    return self.embedding_dropout(emb)
```

## AdaptiveBandwidth(hidden_dim)

State-dependent attention bandwidth from Bekkers' vision model. A scalar
intensity signal (e.g., time_delta) controls how focused or diffuse the
conditioning is. Higher intensity = sharper, narrower attention.

```python
def custom_layers(hidden_dim):
    return {"bw": AdaptiveBandwidth(hidden_dim)}

def custom_embed(self, ...):
    # time_delta controls focus: fast actions get sharp conditioning
    focused = self.bw(action_emb, player_emb, time_delta)  # (B, S, hd)
```

## RatioGate(hidden_dim, mode="spatial")

Reference-normalized ratio gate from PAUSA/Bekkers. Gates by the ratio
of a score to its maximum: "what fraction of the possible signal does
this input capture?" Mode "spatial" takes max over sequence; "channel"
takes max over features.

```python
def custom_layers(hidden_dim):
    return {"ratio": RatioGate(hidden_dim, mode="spatial")}

def custom_embed(self, ...):
    gated = self.ratio(action_emb, player_emb)  # (B, S, hd)
```
