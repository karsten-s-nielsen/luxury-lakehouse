# Player Embedding Explorer

Interactive visualization of player embeddings from the
[Luxury Lakehouse](https://huggingface.co/luxury-lakehouse) soccer analytics
platform.

## What is this?

Each dot represents a player's playing style encoded as a 192-dimensional
behavioral embedding (Football2Vec v2 transformer architecture). The 2D layout
is computed via UMAP cosine projection — players close together have similar
on-pitch behavior patterns.

**Filters:** Position group, competition, level (season vs career).

**Hover:** Player name, position, match count, data sources.

**Click:** Shows nearest neighbors by cosine similarity.

## Data

Embedding data is loaded from
[luxury-lakehouse/embedding-explorer-data](https://huggingface.co/datasets/luxury-lakehouse/embedding-explorer-data)
via DuckDB-WASM (all queries run in your browser).

## Build

This Space is generated by [Apple Embedding Atlas](https://github.com/apple/embedding-atlas):

```bash
pip install embedding-atlas
python scripts/export_embedding_atlas_data.py  # generates Parquet on HF Hub
embedding-atlas \
    embedding-explorer-data/data/embeddings.parquet \
    --no-embedding \
    --x x --y y \
    --neighbors neighbors \
    --text player_name \
    --color position_group \
    --duckdb wasm \
    --export-application ./embedding-explorer/
```
